🔴 Mode infrarouge (interface matérielle)
Un navigateur ne peut pas piloter directement un capteur/émetteur infrarouge : ce module n'est pas simulé par une image teintée en rouge. Il nécessite un canal matériel dédié :
Application Web → Web Serial / WebSocket / MQTT → ESP32 → Caméra IR + LED IR
Matériel requis : module caméra infrarouge (ou capteur thermique) relié à l'ESP32, transmettant l'image au firmware qui la relaie sur le port série déjà connecté (voir "Connecter la carte" ci-contre). Tant que ce canal n'est pas câblé, le bouton reste désactivé — aucune capture IR factice n'est générée.
